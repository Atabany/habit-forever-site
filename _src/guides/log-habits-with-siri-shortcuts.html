Every tap between you and a check-in is a reason to skip it. I built Siri and Shortcuts support into Habit Forever for exactly that reason, and this guide shows what iPhone itself offers first, then the exact phrases and actions the app adds.

What iPhone gives you for free

iPhone has no habit log of its own, but it has three tools that any app can plug into:

  • Siri can run any shortcut in your collection when you say its name.
  • The Shortcuts app shows built-in shortcuts from your apps in its App Shortcuts area, and lets you combine their actions into your own shortcuts.
  • Automations run a shortcut when something happens: a time of day, arriving at or leaving a place, scanning an NFC tag, opening an app, connecting to Wi-Fi or Bluetooth, a Focus turning on, your alarm being stopped and more.

You can also start any shortcut with a physical gesture: the Action button on iPhone 15 Pro and later (Settings > Action Button, swipe to Shortcut, then Choose a Shortcut), or Back Tap, which runs a shortcut when you double-tap or triple-tap the back of your iPhone (Settings > Accessibility > Touch > Back Tap).

If all you want is a spoken nudge, Siri can already create a reminder for you, which works as a simple tracker; see how to track habits on iPhone. To actually log a habit and keep a streak, you need an app that provides the actions.

The three Shortcuts actions

In the Shortcuts app, Habit Forever adds three actions you can use in your own shortcuts and automations:

  • Check In Habit: marks a habit as done for today, without opening the app. It has two optional fields: Amount, for number habits (3 glasses, 25 minutes, 20 pages), and Note, which is saved with the check-in in that habit's history.
  • Get Habit Streak: returns the current streak for a habit as a number you can use in the next action, for example in a notification.
  • Open Habit: opens a specific habit in the app.

For a number habit, fill in Amount so the check-in adds to your total. If you leave it empty, the check-in marks the day as done without a number. You can also set Amount to Ask Each Time, so the shortcut asks you how much when it runs.

Log a specific habit in one sentence

The built-in phrases always ask which habit. To skip that question, make a shortcut for one habit and give it a short name:

  1. Open the Shortcuts app and create a new shortcut.
  2. Add the Check In Habit action from Habit Forever and choose the habit, for example "Drink water".
  3. Set Amount to 1 if it is a number habit.
  4. Name the shortcut "Log water".

Now "Hey Siri, log water" checks it in. The same shortcut can go on the Action button or Back Tap, so one press logs a glass.

Log habits automatically

Automations are where Shortcuts shines for habits. A few that work well with Check In Habit:

  • NFC tag: stick a cheap NFC tag on your vitamin bottle or by the door and check in when you tap your iPhone on it. Apple notes that not all devices support NFC.
  • Arrive: check in "Gym" when you arrive at the gym's address.
  • App: check in "Read" when you open your e-book app, if opening it really means you read.
  • Time of Day: at 9 pm, run Get Habit Streak and show a notification with the number, as an evening nudge.

Be honest with yourself about automatic check-ins. Arriving at the gym is not the same as working out, so for habits like that I prefer an automation that asks first, or the Action button.

How to create an automation

The steps changed in iOS 27, so here are both versions from Apple's Shortcuts guide:

  • iOS 26 and earlier: in Shortcuts, tap Automation (then the add button if you already have automations), tap Create Personal Automation, choose a trigger such as Time of Day or Arrive, set its options, tap Next, and add the Check In Habit action.
  • iOS 27: open the shortcut you made (for example "Log water"), tap Edit, then Automation, and choose a trigger.

By default an automation asks before it runs. You can set it to run without asking; in iOS 27 that is under the shortcut's Info button, Privacy, Allow Running When Locked. Automations are specific to one device.

What to know before you rely on it

  • Check In Habit always logs for today. To fill in a day you missed, open the app; Habit Forever lets you add a check-in for any of the last 7 days.
  • Siri needs to be turned on, and when your iPhone is locked, Siri may ask you to unlock it before a shortcut that opens an app.
  • Habit Forever has no Apple Watch app, so these shortcuts run on iPhone and iPad.

Siri and widgets work well together: Siri for hands-free moments, a widget for a one-tap glance. See how to add a habit tracker widget, or how to track water intake on iPhone for a number habit that suits both.

FAQ

Can I log a habit with Siri?

Yes, with an app that offers App Shortcuts: in Habit Forever, say "Check in on Habit Forever" and Siri asks which habit, checks it in and tells you your streak.

Can Siri log an amount, like glasses of water?

Yes, the Check In Habit action in Shortcuts has an optional Amount field, so a shortcut can log 1 glass, 20 pages or 25 minutes, or ask you each time.

Can I check in a habit automatically?

Yes, a Shortcuts automation can run Check In Habit at a time of day, when you arrive somewhere, open an app or scan an NFC tag.

Does it work from the Action button?

Yes, on iPhone 15 Pro and later you can set the Action button to run a shortcut that contains the Check In Habit action.
